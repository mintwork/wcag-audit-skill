# Security policy

## Reporting a vulnerability

Please report security issues privately through
[GitHub's private vulnerability reporting](https://github.com/mintwork/wcag-audit-skill/security/advisories/new),
not in public issues. You should get a reply within a few days.

## Supported versions

Only the latest release on npm receives fixes.

Releases are published from GitHub Actions with
[npm provenance](https://docs.npmjs.com/generating-provenance-statements), so you can check that a
published version was built from this repository: `npm audit signatures`.
